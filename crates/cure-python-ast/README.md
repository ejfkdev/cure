# cure-python-ast

Arena-based Python AST for [cure](https://github.com/ejfkdev/cure). Models
Python 2.7 and Python 3.x (through 3.15) nodes, including `print`/`exec`/
`raise` statements, `Repr`, f-strings/t-strings, `match`, walrus, PEP 695
type parameters and `lazy import`.

Part of the cure workspace: a fault-tolerant, semantic-preserving simplifier
and formatter for Java, TypeScript/JavaScript and Python.

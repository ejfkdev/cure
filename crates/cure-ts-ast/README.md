# cure-ts-ast

Arena-based TypeScript/JavaScript AST for [cure](https://github.com/ejfkdev/cure).
Provides `TsId` handles, node types, builders, and the `Lang` implementation
that plugs the TS/JS frontend into `cure-engine`.

Part of the cure workspace: a fault-tolerant, semantic-preserving simplifier
and formatter for Java, TypeScript/JavaScript and Python.

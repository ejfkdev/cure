# cure-ts-parser

Fault-tolerant TypeScript/JavaScript parser for
[cure](https://github.com/ejfkdev/cure). Handles ASI, JSX/TSX, decorators,
class fields and static blocks, `using`, import attributes, modern generic
syntax and minified bundles; unparseable regions are preserved verbatim.

Part of the cure workspace: a fault-tolerant, semantic-preserving simplifier
and formatter for Java, TypeScript/JavaScript and Python.
